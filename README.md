# Codeblog

Codeblog is a web application that lets users write, share, and explore articles about coding.

## Website

Visit the website at [https://codeblog.tonytran.dev](https://codeblog.tonytran.dev).

## Technologies

**Database**: PostgreSQL  
**Backend / Frontend**: Next, Prisma, Clerk, ShadCN, Tailwind CSS  
**Deployment / Tools**: Vercel, Cloudflare, Neon, GCP, Ngrok
